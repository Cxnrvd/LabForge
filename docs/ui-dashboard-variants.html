Pick a personality

Soft Light directions all stay calm but pick different references; Ops Console directions all stay dense but pick different intensities.

VariantReferenceBest userMoodImplementation cost
C1 · Editorial CreamNotion / Apple NotesSolo practitioner, docs authorQuiet, consideredLow — type + spacing only
C2 · Crisp White SaaSStripe / Vercel / LinearTrial users, hosted-product buyersProfessional, modernLow — well-known patterns
C3 · Material PaperGoogle consumer appsCross-functional / non-engineerFriendly, approachableMedium — multi-color states
E1 · GitHub DarkGitHub Actions / Vercel logsDevops engineerClean, focusedLow — close to current dark
E2 · Datadog ColorDatadog / New RelicEnterprise / multi-teamVivid, productiveHigh — real charts everywhere
E3 · Bloomberg AmberBloomberg TerminalPower user, finance-adjacentIconic, intenseMedium — but high commitment
My take. If you want Soft Light to feel like LabForge and not a generic SaaS, pick C1 · Editorial Cream — the serif gives it identity that C2 lacks. If you want broad adoption beyond hardcore security folks, C3 · Material Paper wins.
For Ops Console, E1 · GitHub Dark is the safest, fastest-to-ship, and most familiar to your audience. E2 · Datadog Color is the most impressive in a demo but is the heaviest lift. E3 · Bloomberg Amber is the most memorable — if you go this route, ship it as an opt-in /terminal mode rather than the default.
Pairing recommendation: C1 + E1 if you want a coherent product (calm by default, dense when needed). Tell me which combo wins and I'll extend it across canvas / node config / CVE picker / generate / live-run.
