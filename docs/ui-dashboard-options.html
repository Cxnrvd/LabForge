Dashboard exploration · pick a direction

Five takes on the LabForge dashboard.

Same product, same data, five distinct visual languages. Each one assumes a different user mindset — from the SOC analyst who lives in the dark, to the CISO who wants something calm and reportable, to the operator who treats their host like a NOC wall. Scroll, compare, pick a direction. We can then go deep on the chosen one and extend the language to every other screen.

Option A

Tactical SOC

refined dark · cyan accent · current direction

Dense, professional, war-room aesthetic. Sidebar navigation, color-coded pills for state, monospace for any number that matters. Feels at home next to Splunk, Wazuh and Kibana.

Compare at a glance

Each direction is internally consistent — pick one and we'll extend the language to canvas, node config, CVE picker, validation, generate, and live-run screens.

Direction Best user Density Energy Demo / sell Daily use
A · Tactical SOC SOC analyst, blue team High Calm-serious Solid Strong
B · Neon Glass Red team, demo crowd Medium Dramatic ★ Best Tiring after hours
C · Soft Light CISO, docs, screenshots Low Calm Good ★ Best
D · Pure Terminal Power user, CTF folks High Focused Niche Cult-favourite
E · Ops Console Multi-lab operator, NOC Very high Watchful Strong for enterprise Strong for power users
My take. If forced to pick: Option A (Tactical SOC) as the default, with Option E (Ops Console) as a dedicated /ops view for users running many labs, and Option D (Pure Terminal) as a real labforge tui command shipped alongside the GUI. Options B and C are mood pieces — keep them as references for marketing screenshots and the docs site, respectively. Tell me which one you want to commit to and I'll build out the rest of the journey in that language.
